# 🎄 Natal da Casa21

O Natal da Casa21 agora é open source. O planejamento é aberto, o trenó aceita PR e o deploy vai ser presencial.

Vamos decorar a casa com pisca-pisca e montar uma árvore com enfeites impressos em 3D, representando quem faz parte da comunidade interna da Vinteum. Porque personalizar o VS Code é fácil. Queremos ver personalizar o Natal inteiro.

## 🛠️ Objetivos do projeto

### Iluminação da Casa21

Espalhar pisca-pisca pela casa e finalmente ter um motivo legítimo para deixar tudo piscando em produção.

**Critério de aceite:** clima natalino, cabos organizados e nenhum incidente que exija um post-mortem.

### Árvore da comunidade

Montar uma árvore de Natal com dependências afetivas e enfeites feitos na impressora 3D. Cada membro da comunidade vira um componente — dessa vez, com personalidade própria.

O planejamento inicial dos enfeites inclui:

| Personagem | Ideia de enfeite |
| --- | --- |
| 🎅 Lucas | Papai Noel |
| 🏄 Pins | Em uma prancha de surf |
| 🏎️ Noctus | Em um carrinho de kart |
| 🎁 Restante da comunidade | Definir referências e abrir uma issue para cada personagem |

### Mutirão de decoração: deploy presencial

Marcar um dia para decorar a Casa21 juntos. Vamos instalar as dependências, montar a árvore e, quem sabe, fazer um churrasco.

**Data: a definir com a comunidade.**

Informe seus dias e horários disponíveis na [issue de planejamento](https://github.com/thaiz-21/natal-casa21/issues/1) para fecharmos a janela de deploy. Neste projeto, “participar remotamente” não pendura pisca-pisca.

## 🤝 Como contribuir

### Sugira ideias

[Abra uma issue](https://github.com/thaiz-21/natal-casa21/issues/new) com sugestões de decorações, personagens, referências e objetos que representem a galera. “Seria legal ter…” é um começo. Para os enfeites da comunidade, abra uma issue para cada personagem.

### Envie modelos e propostas

Mande um pull request com modelos 3D, desenhos, arquivos para impressão ou propostas de decoração.

**Se usar um modelo de terceiros, inclua a fonte e a licença.** Até o Papai Noel respeita dependências.

### Ajude na produção e na montagem

Precisamos de gente para imprimir, pintar, montar e pendurar. Aqui, trabalho manual também conta como contribuição no GitHub — pelo menos no nosso coração.

### Apareça no mutirão

Compartilhe na [issue de planejamento](https://github.com/thaiz-21/natal-casa21/issues/1) os dias e horários em que pode ajudar e quais materiais consegue trazer.
